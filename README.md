# MDPad

Простой редактор Markdown для macOS. Разметка сразу отображается оформленным текстом, исходные символы видны только на строке с курсором, как в Typora и Live Preview в Obsidian.

## Возможности

- Живое превью: заголовки, списки с висячим отступом, таблицы с подбором ширины столбцов, чекбоксы, цитаты, картинки, подсветка кода (~140 языков).
- Совместимость с Obsidian: свойства (front matter), выноски `> [!note]`, `[[вики-ссылки]]` с поиском по хранилищу.
- Диаграммы Mermaid, экспорт в PDF и печать.
- Оглавление (Cmd+Shift+O), счётчик слов, исходный вид (Cmd+/).
- Копирование с форматированием для почты и мессенджеров (Cmd+Shift+C).
- Умная вставка: HTML превращается в markdown, картинки из буфера сохраняются в `assets/`.
- Редактирование таблиц: Tab по ячейкам, Enter добавляет строку, автовыравнивание.
- Автосохранение, вкладки, подхват изменений файла извне.

## Сборка

Нужны Command Line Tools (полный Xcode не требуется) и Node.js.

```bash
./build.sh            # собрать build/MDPad.app
./build.sh --install  # собрать и поставить в /Applications
```

## Устройство

- `Sources/` - обёртка на Swift: NSDocument, меню, настройки (SwiftUI), экспорт в PDF.
- `web/src/` - редактор на CodeMirror 6, собирается esbuild в один `editor.js`.
